# سرویس هسته - نگاشت ورودی (Core Service - Input Mapper)

این پروژه یک اپلیکیشن C++ برای ویندوز است که ورودی‌های دستگاه‌های سخت‌افزاری (مانند کیبورد و ماوس) را کپچر کرده و آن‌ها را به یک کنترلر گیم‌پد مجازی (مانند کنترلر Xbox) نگاشت می‌کند. این برنامه از پروفایل‌های مبتنی بر JSON برای نگاشت منعطف ورودی‌ها استفاده می‌کند.

این ابزار به شما اجازه می‌دهد بازی‌هایی که فقط از گیم‌پد پشتیبانی می‌کنند را با کیبورد و ماوس بازی کنید.

## ویژگی‌ها

- **نگاشت مبتنی بر پروفایل:** ایجاد و جابجایی بین پروفایل‌های مختلف نگاشت با استفاده از فایل‌های ساده JSON.
- **ورودی خام (Raw Input):** استفاده از Windows Raw Input API برای کپچر ورودی‌ها، که سازگاری و عملکرد بالا را تضمین می‌کند.
- **شبیه‌سازی کنترلر مجازی:** استفاده از درایور ViGEmBus برای ایجاد و مدیریت کنترلرهای مجازی Xbox 360.
- **تشخیص داینامیک دستگاه‌ها:** شناسایی دستگاه‌های HID متصل شده در زمان اجرا.
- **سیستم ماکرو (Macros):** قابلیت تعریف توالی‌های پیچیده از کلیدها با زمان‌بندی دقیق برای بازی‌های مبارزه‌ای و اکشن.

## اجزای اصلی سیستم

1.  **Virtual Controller:** مسئول تعامل با درایور ViGEmBus برای شبیه‌سازی دسته.
2.  **Raw Input Handler:** وظیفه دریافت مستقیم سیگنال‌های سخت‌افزاری از سیستم‌عامل.
3.  **Mapping Engine:** موتور پردازشگر که قوانین تعریف شده در پروفایل را روی ورودی‌ها اعمال می‌کند.
4.  **Profile Manager:** مدیریت بارگذاری و فعال‌سازی فایل‌های تنظیمات (JSON).

## پیش‌نیازها

قبل از ساخت پروژه، باید پیش‌نیاز زیر را نصب کنید:

- **[درایور ViGEmBus](https://github.com/ViGEm/ViGEmBus/releases):** این یک درایور حالت هسته (kernel-mode) الزامی است. برای کارکرد برنامه باید آن را دانلود و نصب کنید.

وابستگی‌های زیر به طور خودکار توسط CMake مدیریت می‌شوند:

- **nlohmann/json:** یک کتابخانه C++ برای خواندن و تجزیه پروفایل‌های JSON.

## نحوه ساخت (Build)

این پروژه از CMake برای تولید فایل‌های ساخت استفاده می‌کند.

### پیش‌نیازهای نرم‌افزاری

- یک کامپایلر C++ که از C++17 پشتیبانی کند (مانند MSVC در Visual Studio).
- [CMake](https://cmake.org/download/) (نسخه 3.10 یا بالاتر).
- [Git](https://git-scm.com/downloads/).

### مراحل ساخت

1.  **کلون کردن مخزن:**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **ایجاد دایرکتوری build:**
    ```bash
    mkdir build
    cd build
    ```

3.  **پیکربندی پروژه:**
    ```bash
    cmake ..
    ```

4.  **ساخت پروژه:**
    ```bash
    cmake --build .
    ```
    این کار فایل اجرایی `CoreService.exe` را در دایرکتوری `build/Debug` یا `build/Release` ایجاد می‌کند.

## نحوه استفاده

1.  مطمئن شوید **ViGEmBus** نصب شده است.
2.  فایل اجرایی را اجرا کنید:
    ```bash
    .\CoreService.exe
    ```
3.  برنامه در پس‌زمینه شروع به کار کرده، پروفایل‌های موجود در `src/CoreService/Profiles/` را بارگذاری کرده و اولین پروفایل را فعال می‌کند.
4.  در حالی که برنامه در حال اجراست، ورودی‌های کیبورد و ماوس شما بر اساس قوانین پروفایل فعال به ورودی‌های گیم‌پد مجازی تبدیل می‌شوند.

## ساخت پروفایل‌ها

پروئایل‌ها فایل‌های JSON هستند که نحوه نگاشت ورودی‌ها را تعریف می‌کنند. می‌توانید فایل‌های `.json` خود را ایجاد کرده و در دایرکتوری `src/CoreService/Profiles/` قرار دهید.

### نمونه ساختار پروفایل

```json
{
  "profileName": "My Custom Profile",
  "actions": [
    {
      "name": "Jump",
      "keyboardMouse": { "primary": "Spacebar" },
      "xboxController": { "primary": "A_Button" }
    },
    {
      "name": "Fire",
      "keyboardMouse": { "primary": "Mouse_LeftClick" },
      "xboxController": { "primary": "RT" }
    }
  ]
}
```

## سیستم‌های پیشرفته (مثال‌های آموزشی)

در این پروژه مثال‌هایی برای سیستم‌های پیچیده‌تر نیز وجود دارد:
- **Dismemberment System:** در فایل `NPCLogicExample.h` منطقی برای مدیریت وضعیت‌های دشمن و قطع عضو در بازی‌های مبارزه‌ای طراحی شده است.
- **Combo Macros:** پروفایل `FightingGameCombos.json` نشان‌دهنده نحوه تعریف ماکروهای چند مرحله‌ای برای اجرای حرکات خاص است.
